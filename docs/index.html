Nexus
a wireless control mesh

Six M5Stack devices on one ESP‑NOW mesh — no router. A touch macro deck that types into your Mac, an e‑ink remote that runs the Mac and the TV, an AI camera that locks the screen when you walk away, and an RGB strip that reads your RAM.

The mesh

Six nodes, one radio

Every device is an ESP32 on ESP‑NOW channel 1, peer‑to‑peer. They run on battery and talk directly — no Wi‑Fi, no cloud, no pairing server.

the dongle

T‑Dongle S3

LilyGO ESP32‑S3 · USB‑A

Plugs into the Mac and enumerates as a real USB keyboard + mouse. Its 0.96″ ST7735 shows the last action; BOOT toggles HID output as a safety gate.

USB‑HID + ESP‑NOW coexist on one S3
the deck

CoreS3

M5Stack ESP32‑S3 · 2″ touch

LVGL macro pad: swipe between Dev / System / Snippets profiles and a Monitor page, with animated buttons and a battery bar. Also relays Mac stats to the mesh.

LVGL 8 over M5Unified
the remote

Slate

M5Paper · 4.7″ e‑ink touch

A paginated e‑ink touch remote — Media, TV (IR), Mac macros, Monitor. The side wheel flips pages. One surface drives the Mac and the living‑room TV.

GT911 touch · wheel‑paged
the guard

Core2 + UnitV2

M5Stack ESP32 + AI camera

The UnitV2 AI camera watches for a face over UART. No face for 15 s while armed → the Core2 fires ⌃⌘Q and locks the Mac. On‑screen ARM/DISARM.

face detect → auto‑lock
the monitor

StickC Plus2 + SK6812

M5Stack ESP32 + 30 LEDs

Drives a flex strip as an ambient MEM / GPU / CPU / DISK gauge — green→amber→red as it fills. Switch the metric from the remote. Doubles as the TV IR blaster.

NeoPixel bar + IR TX (GPIO19)
the glue

Shared protocol

one versioned packet

A versioned ESP‑NOW packet and a shared macro table every node links against: key combos, strings, media keys, metric switches, IR commands, stats.

one header, five firmwares

The TV remote

Make the stick an IR blaster and point it at a 65″ TV. Then the fun part…

War story · infrared

“Can this control my old Sharp 65″ TV by IR? LOL!”

The “Sharp” turned out to be Hisense‑made (model LC‑50P7000U), so every Sharp code did nothing. Two problems stacked: the wrong code family, and IRremoteESP8266 wanting its own byte order. The fix was the official Hisense NEC codes on address 0x04, sent through encodeNEC(). The TV turned on.

PWR 0x70 VOL+ 0xA6 VOL− 0xA5 INPUT 0x73 addr 0x04 · NEC
